# rbhunlimited

Website for RBH Unlimited, served by GitHub Pages at https://rbhunlimited.com.

- `index.html`, `assets/`: the static site
- `CNAME`: custom domain for GitHub Pages
- Contact form: delivered by [FormSubmit](https://formsubmit.co) to rbhul@rbhunlimited.com
- `_server-php/` (not committed): the old PHP mail handler, kept locally for PHP hosting
